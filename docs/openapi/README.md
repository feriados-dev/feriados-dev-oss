# OpenAPI

Este diretorio documenta a API self-hosted Brasil-only.

- `feriados-v1.openapi.yaml`: contrato publico da v1 OSS, sem autenticacao e sem billing.

O contrato OpenAPI tambem serve como contexto estruturado para ferramentas de
IA, geracao de clientes, revisao de mudancas de API e validacao de exemplos.
