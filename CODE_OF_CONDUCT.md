# Codigo de Conduta

## Nosso compromisso

Queremos manter este projeto util, direto e respeitoso para quem usa, reporta dados, abre issues ou contribui com codigo.

## Comportamentos esperados

- Ser claro e objetivo.
- Tratar discordancias tecnicas com respeito.
- Presumir boa fe, mas pedir fontes quando dados forem contestados.
- Manter discussoes focadas no problema.
- Aceitar revisao como parte normal do trabalho.

## Comportamentos inaceitaveis

- Ataques pessoais, insultos ou assedio.
- Comentarios discriminatorios.
- Exposicao de dados pessoais sem consentimento.
- Pressao para aceitar mudancas sem fonte ou sem revisao.
- Spam, autopromocao fora de contexto ou discussao comercial irrelevante.

## Aplicacao

Issues, PRs ou comentarios que violem este codigo podem ser editados, ocultados ou fechados. Contribuidores que insistirem em comportamento abusivo podem ser bloqueados.
