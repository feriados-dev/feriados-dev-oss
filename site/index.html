01 O projeto

Uma base brasileira. Na sua infraestrutura.

Consulte feriados nacionais, estaduais e municipais com uma API que pode ser instalada, modificada e operada por você. Sem cadastro, sem API key e sem limites comerciais.

A

Dados organizados por localidade

As datas nacionais, estaduais e municipais seguem a hierarquia de cada lugar.

B

Você opera e adapta

PostgreSQL, Node.js e Docker Compose. O código fica no seu ambiente.

C

Aberto para contribuição

MIT, dados versionados em SQL e um fluxo claro para revisar mudanças.

02 Comece aqui

Seu próximo calendário começa no terminal.

Clone o repositório e suba a API e o banco localmente com Docker Compose.

Ver instruções e requisitos ↗
terminal shell 
# Obtenha o código
git clone https://github.com/feriados-dev/feriados-dev-oss.git
cd feriados-dev-oss

# Inicie a API e o PostgreSQL
cp .env.example .env
docker compose up --build
Primeira consulta GET /v1/holidays/year/2026
